# 📦 Duka Stock & POS Profit Tracker

A lightweight full-stack inventory management and Point-of-Sale (POS) web application built with **Python**, **Flask**, **SQLite**, and **Bootstrap 5**. Designed for small retail businesses (*dukas*) to track stock levels, monitor low-stock alerts, log daily sales, and export inventory reports.

## ✨ Features
- **Real-Time Inventory Tracking:** Add items with buying price, selling price, category, and stock quantity.
- **One-Click POS Sales & Restocking:** Record sales (`-1 Sold`) or restocks (`+1`) with automatic database persistence.
- **Daily Revenue & Realized Profit:** Automatically calculates daily sales revenue and net profit earned.
- **Low-Stock Alerts:** Highlights products with 5 or fewer units remaining.
- **Instant Search & Category Filtering:** Filter inventory items live without page reloads.
- **CSV Report Export:** Download a timestamped `.csv` inventory valuation report for Excel or WhatsApp sharing.

## 🛠️ Tech Stack
- **Backend:** Python 3, Flask, SQLite3
- **Frontend:** HTML5, Bootstrap 5 (Dark Mode), Vanilla JavaScript
